El panel corre dentro de un contenedor Docker y, por diseño de seguridad, no tiene permiso para tocar el firewall del servidor directamente. Esta página solo te muestra qué comando correr — cópialo y ejecútalo por SSH en el servidor (con sudo).

Detectado en el servidor

UFW: activo, deniega todo el tráfico entrante por defecto salvo lo permitido explícitamente.

fail2ban: activo, con jails sshd, nginx-bad-request, nginx-botsearch, nginx-scanner (bloquea IPs con comportamiento abusivo).

Para ver el estado real y actualizado en cualquier momento, corre por SSH:

sudo ufw status verbose   sudo fail2ban-client status

Nota: Docker no pasa por UFW para sus puertos publicados, así que estos comandos no afectan a tus proyectos en contenedores (ya son accesibles desde internet igual). Solo sirven para algo que corra nativo en el host, sin Docker.

Rango para apps de 1 clic (20000-20999)

Cada vez que instalas una app con "Instalar app" se le asigna un puerto libre de este rango. Como esos contenedores publican el puerto igual que los demás, ya son accesibles desde internet en cuanto se crean — no necesitas abrir nada en ufw para eso. El comando de abajo solo tendría efecto si algún día corres algo en ese rango fuera de Docker.

sudo ufw allow 20000:20999/tcp

Puerto personalizado

sudo ufw allow <puerto>/tcp
